# API 接口文档
后端框架：Laravel
请求基础地址：/api/v1
统一请求格式：JSON
统一返回格式：
{
  "code": 200, // 200成功 4xx客户端错误 5xx服务端错误
  "msg": "提示文字",
  "data": {} // 返回数据主体
}

## 全局公共接口
### 1. 用户登录
请求地址：POST /api/v1/login
请求参数：
{
  "username": "string",
  "password": "string"
}
返回示例：
{
  "code":200,
  "msg":"登录成功",
  "data":{
    "token":"xxxx",
    "user_info":{}
  }
}

## 错误码对照表
| 错误码 | 含义             |
| ------ | ---------------- |
| 200    | 请求成功         |
| 401    | 未登录/Token失效 |
| 403    | 无操作权限       |
| 404    | 接口不存在       |
| 500    | 服务器异常       |
| 10001  | 参数校验失败     |
