# 单人快速开发技术栈推荐

> 面向 MVP 演示，单人全栈，公司人少、并发低、订货时间分散。

---

## 核心推荐：Inertia.js + React + shadcn/ui

**一句话：用 Laravel 官方推荐的"无 API"方案，React 写页面但不写 REST API，开发速度和 Livewire 一样快，体验和纯 React 一样好。**

---

## 为什么不选 Livewire

| 对比项 | Livewire | Inertia.js + React |
| :--- | :--- | :--- |
| **表格交互** | 每次筛选/分页发请求等 200ms，体验卡顿 | 本地状态管理，筛选即时响应，后台静默同步 |
| **复杂组件** | 地图、图表、实时数据几乎做不了 | 腾讯地图、Recharts、WebSocket 即插即用 |
| **UI 组件库** | Flux UI 新出不久，组件少，文档不完善 | shadcn/ui 组件齐全（表格、对话框、日期、下拉），社区活跃 |
| **AI 扩展** | 搜索联想、流式输出实现困难 | 天然支持，未来无缝升级 |
| **代码量** | PHP + Blade 混着写，后期改 React 要重写 | 前端就是 React，以后拆成纯 API 不需要重写页面 |
| **学习成本** | 要理解 Livewire 生命周期（mount/render/update） | 就是写 React，会 React 就会 Inertia |

**Livewire 适合内容型后台（CMS、配置页），你的项目是数据密集型（订单/拣货/配送/财务），React 更合适。**

## 完整技术栈

### 后端

| 选型 | 版本 | 说明 |
| :--- | :--- | :--- |
| **Laravel** | 13.x | 最新稳定版，Breeze 官方支持 Inertia |
| **PHP** | 8.3 | 匹配 Laravel 13 要求 |
| **数据库** | MySQL 8.0 | 事务、JSON 字段、CTE 查询 |
| **缓存+队列+会话** | Redis | 一个 Redis 搞定三件事，轻量 |
| **认证** | Laravel Breeze (Inertia React) | 官方脚手架，登录/注册/密码重置开箱即用 |
| **权限** | Spatie Laravel Permission | RBAC 角色权限，文档完善 |
| **图片存储** | 本地 / 阿里云 OSS | MVP 阶段本地即可 |

### 管理后台（Web）

| 选型 | 说明 |
| :--- | :--- |
| **Inertia.js** | Laravel 官方"无 API"方案，Controller 直接返回数据给 React |
| **React 18** | 前端框架 |
| **TypeScript** | 类型安全，减少运行时错误（可选，但强烈推荐） |
| **shadcn/ui** | 基于 Tailwind + Radix，复制粘贴即用，组件齐全 |
| **Tailwind CSS** | 原子化 CSS，不写 CSS 文件 |
| **TanStack Table** | 复杂表格（筛选、排序、分页、虚拟滚动） |
| **TanStack Query** | 数据获取、缓存、乐观更新（Inertia 里可选，但用了更爽） |
| **Zustand** | 轻量状态管理（跨组件共享用户状态、侧边栏折叠等） |
| **React Router** | 页面路由（Inertia 封装了，基本不需要手动配置） |

### 微信小程序

| 端 | 技术 | 说明 |
| :--- | :--- | :--- |
| **商家端** | Taro 4 + React + TypeScript | 智能搜索下单、购物车、订单查看；与管理后台技术栈统一，复用类型/API 层/状态管理 |
| **司机端** | 原生微信小程序 | 配送任务、轨迹上报、拍照签收；页面少、原生能力多（定位/相机/地图），原生开发更快 |

#### 商家端（Taro）配套选型

| 层级 | 推荐 | 说明 |
| :--- | :--- | :--- |
| UI 组件库 | NutUI-Taro | 京东系，与 Taro 配合最稳，覆盖电商场景（购物车、商品卡片、步骤条） |
| 状态管理 | Zustand | 与管理后台一致，购物车、用户信息跨页面共享 |
| 数据请求 | 封装 `@tarojs/taro.request` | 统一 Token 注入 + 错误处理（Laravel Sanctum） |
| 样式 | weapp-tailwindcss | 小程序版 Tailwind，保持与管理后台一致的样式习惯 |
| 地图 | 原生 `<map>` 组件 | Taro 直接支持平台组件，无需额外封装 |

#### 预期复用边界（管理后台 ↔ Taro 商家端）

- ✅ 可复用：TypeScript 类型定义、API 请求层、Zustand store、业务工具函数（抽成 npm workspace 公共包）
- ⚠️ 需重写：页面 JSX 和样式（小程序无 DOM，`<view>` ≠ `<div>`），预期复用 30–50% 而非 80%
- ⚠️ 注意：Taro 跟进微信新 API 通常慢 1–3 个月；长列表需分页/虚拟列表

## Inertia.js 工作原理（为什么快）

```
传统 React + API 方案（工作量大）：
浏览器 → React 页面 → API 请求 /api/orders → Laravel 解析 → JSON 返回 → React 渲染

Inertia.js 方案（省掉 API 层）：
浏览器 → Inertia 请求 /orders → Laravel Controller 查询 → Inertia::render('Orders/Index', $data)
         → 返回一个 JSON+XHR 特殊响应 → React 组件直接拿到数据渲染
```

**你不需要写：**
- ❌ API Controller
- ❌ API Resource / Transformer
- ❌ api.php 路由（除了给小程序用的）
- ❌ CORS 配置
- ❌ 前后端联调

**你只需要写：**
- ✅ Laravel Web Controller（正常写）
- ✅ React 页面组件（正常写）
- ✅ 一条 web.php 路由指向 Controller

## 一条典型的 Inertia 路由和 Controller

```php
// routes/web.php
Route::middleware(['auth', 'verified'])->group(function () {
    Route::get('/orders', [OrderController::class, 'index']);
    Route::get('/orders/{order}', [OrderController::class, 'show']);
});
```

```php
// app/Http/Controllers/Web/OrderController.php
namespace App\Http\Controllers\Web;

use App\Http\Controllers\Controller;
use App\Models\Order;
use Illuminate\Http\Request;
use Inertia\Inertia;

class OrderController extends Controller
{
    public function index(Request $request)
    {
        $orders = Order::query()
            ->with(['customer', 'items'])
            ->when($request->status, fn($q, $status) => $q->where('status', $status))
            ->when($request->search, fn($q, $search) => $q->where('order_no', 'like', "%{$search}%"))
            ->latest()
            ->paginate(20);

        return Inertia::render('Orders/Index', [
            'orders' => $orders,
            'filters' => $request->only(['status', 'search']),
        ]);
    }

    public function show(Order $order)
    {
        return Inertia::render('Orders/Show', [
            'order' => $order->load(['items.product', 'customer', 'deliveryTask']),
        ]);
    }
}
```

```tsx
// resources/js/Pages/Orders/Index.tsx
import { Head } from '@inertiajs/react';

      </div>
    </>
```

## 快速启动命令

```bash
# 1. 创建 Laravel 项目
composer create-project laravel/laravel susong-platform
cd susong-platform

# 2. 安装 Breeze (Inertia + React)
composer require laravel/breeze --dev
php artisan breeze:install inertia

# 3. 选择 React + TypeScript
# Breeze 会自动安装 React、Inertia、Tailwind、shadcn/ui 基础

# 4. 安装额外依赖
npm install @tanstack/react-table zustand

# 5. 安装 shadcn/ui 组件
npx shadcn add table button dialog form input select badge card tabs

# 6. 安装后端包
composer require spatie/laravel-permission

# 7. 初始化数据库
php artisan migrate

# 8. 启动开发
npm run dev          # Vite 前端热更新
php artisan serve    # Laravel 后端
```

## 与小程序的关系

```
┌──────────────────────┐         ┌──────────────────────┐
│   管理后台 Web       │         │   商家端小程序       │
│   (Inertia + React)  │         │   (Taro 4 + React)   │
│                      │         │                      │
│   /orders            │         │   Taro.request({     │
│   /products          │◄───────►│     url: '/api/...'  │
│   /deliveries        │         │   })                 │
└──────────────────────┘         └──────────┬───────────┘
                                            │
                               ┌────────────▼───────────┐
                               │   司机端小程序         │
                               │   (原生微信开发)       │
                               │   wx.request 调 API    │
                               └────────────┬───────────┘
            │                              │
            │  共用同一套 Laravel 后端      │
            │                              │
            ▼                              ▼
┌──────────────────────────────────────────────────────┐
│              Laravel 后端                             │
│   web.php  →  Inertia 页面 (管理后台)                 │
│   api.php  →  JSON API (小程序)                       │
└──────────────────────────────────────────────────────┘
```

**关键点**：
- 管理后台走 `web.php` + Inertia，不需要 API
- 小程序走 `api.php` + JSON，不影响管理后台
- 两者共享 Model、Service、Event、Queue

## 总结

| 你的需求 | Inertia.js + React 的匹配度 |
| :--- | :--- |
| 一个人开发 | ⭐⭐⭐⭐⭐ 省掉 API 层，工作量接近 Livewire |
| 快速出 MVP | ⭐⭐⭐⭐⭐ Breeze 脚手架开箱即用，shadcn/ui 复制粘贴 |
| 展示效果好 | ⭐⭐⭐⭐⭐ 页面不刷新、筛选即时响应、交互流畅 |
| 未来扩展 AI | ⭐⭐⭐⭐⭐ 前端就是 React，AI 功能无缝接入 |
| 并发不高 | ⭐⭐⭐⭐⭐ Inertia 的服务端渲染在本地场景完全够用 |

> **最终建议：别纠结 Livewire 了，直接上 Inertia.js + React + shadcn/ui。这是你当前阶段开发效率最高、未来扩展最灵活的选择。**
