# 本地配送平台（含生鲜）系统功能清单

> 基于 Laravel 技术栈，区分冷链和非冷链的本地生鲜/农产品配送平台。

---

## 一、用户与权限管理模块

### 1.1 用户管理

- 用户注册/登录（用户名+手机号+邮箱多方式登录）
- 密码管理（修改密码/重置密码）
- 双因素认证
- 用户信息维护（头像/名称/手机号/邮箱）
- 用户状态管理（启用/禁用）
- 会话管理

### 1.2 角色管理

- 角色创建/编辑/删除
- 角色状态管理
- 预置角色：管理员/运营/财务/司机/拣货员/商家

### 1.3 权限管理

- 权限创建/编辑/删除
- 菜单权限配置（是否菜单项标识）
- 路由权限标识
- 权限排序

### 1.4 角色授权

- 角色-权限关联配置
- 用户-角色关联配置
- 基于角色的访问控制（RBAC）
- 商家数据隔离（Global Scope 自动注入 merchant_id）

## 二、组织主体模块（供应商/商家/司机）

- 自动生成待采需求（根据订单汇总）
- 手工添加待采需求
- 待采状态管理（待生成/已生成采购单）

### 4.3 采购入库管理

- 入库单创建（关联采购单）

- 实际入库金额记录

- 入库时间记录

## 五、客户直采模块（商家→平台采购）

### 5.1 购物车

- 加入购物车（商品/SKU/数量/单价）
- 购物车数量修改
- 购物车商品删除
- 按商家隔离购物车

### 5.2 客户订单管理

- 订单创建（从购物车结算）
- 订单号自动生成
- 收货地址选择
- 一日两配：上午批次（午餐）/下午批次（晚餐）
- 订单总金额+运费计算
- 支付方式选择
- 支付状态管理
- 订单状态流转：待拣货→配送中→已签收→已锁定→已关闭

### 5.3 订单明细

- 订单商品明细（SKU/数量/单价/小计）
- 称重改价：实际称重数量录入
- 实际结算金额自动计算
- 称重差异超 20% 自动标记待运营审核

### 5.4 常购清单

- 基于商家历史采购频次自动生成常购商品列表
- 首页/搜索页优先展示

### 5.5 订单一键复购

- 基于历史订单快速复购
- 支持整单复购或部分商品勾选加购
- 周期性复购预测（智能补货推荐）

## 模块关系与核心业务流

### 核心业务流程

1. **平台统采流程**：待采清单 → 生成采购单 → 供应商接单 → 备货发货 → 采购入库
2. **客户直采流程**：商家选品 → 加入购物车 → 提交订单 → 支付 → 拣货 → 配送 → 签收
3. **差异处理流程**：发现差异 → 记录差异单 → 责任认定 → 金额调整 → 审计归档
4. **财务结算流程**：订单完成 → 生成应收 → 差异调整 → 客户结算 → 供应商结算
5. **商家智能下单流程**：输入关键词 → AI 解析/联想 → 关联采购历史 + 主推商品 + 同类推荐 → 快速加购 → 提交订单

### 表依赖关系

- users 表依赖 roles 表
- merchants 表依赖 routes 表
- products 表依赖 categories 表
- product_skus 表依赖 products 表
- product_visibility 表依赖 products 和 merchants 表
- inventories 表依赖 warehouses 和 product_skus 表
- inventory_logs 表依赖 warehouses、product_skus 和 users 表
- orders 表依赖 merchants 表
- order_items 表依赖 orders 和 product_skus 表
- delivery_tasks 表依赖 drivers、routes 和 users 表
- picking_lists 表依赖 warehouses、orders、product_skus 和 users 表
- delivery_proofs 表依赖 delivery_tasks 和 orders 表
- accounts_receivable 表依赖 merchants 和 orders 表
- audit_logs 表依赖 users 表
