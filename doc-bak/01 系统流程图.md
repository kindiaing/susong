## 二、平台统采流程

```mermaid
flowchart LR
    Start(["开始"]) --> A["订单汇总<br/>生成待采需求"]
    A --> B{生成方式}
    B -->|"自动汇总"| C["待采清单"]
    B -->|"手工添加"| C
    C --> D["创建采购单<br/>关联供应商"]
    D --> E["采购单状态：<br/>待接单"]
    E --> F["供应商接单"]
    F --> G["备货中"]
    G --> H["已发货"]
    H --> I["采购入库<br/>实际数量/金额录入"]
    I --> J["入库完成"]
    J --> K(["结束"])
```

## 三、客户直采流程（商家下单）

```mermaid
flowchart TD
    Start(["商家打开小程序"]) --> A["搜索/浏览商品"]
    A --> B["选择商品规格<br/>加入购物车"]
    B --> C{"继续选购？"}
    C -->|是| A
    C -->|否| D["进入购物车结算"]
    D --> E["选择收货地址"]
    E --> F["选择配送批次<br/>上午(午餐) / 下午(晚餐)"]
    F --> G["提交订单"]
    G --> H{"支付方式"}
    H -->|余额支付| I["扣减余额"]
    H -->|账期支付| J["记账挂账"]
    H -->|预付款| K["预付款扣减"]
    I --> L["订单状态：待拣货"]
    J --> L
    K --> L
    L --> M["拣货任务分配"]
    M --> N["拣货中<br/>称重改价（如需要）"]
    N --> O{"称重差异>20%？"}
    O -->|是| P["标记待运营审核"]
    O -->|否| Q["拣货完成"]
    P --> Q
    Q --> R["配送任务分配<br/>关联司机/线路"]
    R --> S["配送中<br/>GPS轨迹上报"]
    S --> T["到达目的地"]
    T --> U["签收存证<br/>拍照/电子签名/温度记录"]
    U --> V["订单状态：已签收"]
    V --> W["生成应收账款"]
    W --> End(["流程结束"])
```

## 四、智能下单流程（小程序商家端）

```mermaid
flowchart TD
    Start(["商家输入关键词<br/>如：鸡"]) --> A["AI 语义解析<br/>整理关键字"]
    A --> B["检索采购历史"]
    B --> C["召回历史买过的<br/>鸡相关产品"]
    A --> D["检索运营主推"]
    D --> E["召回近期主推<br/>鸡类产品"]
    A --> F["检索同类商品"]
    F --> G["召回同类型<br/>未购买过的鸡产品"]
    C --> H["智能排序展示"]
    E --> H
    G --> H
    H --> I["最近买过 > 常购 > 主推 > 同类推荐"]
    I --> J["商家选择商品"]
    J --> K{"语音/自然语言下单？"}
    K -->|是| L["AI 助手多轮对话<br/>确认规格/数量"]
    K -->|否| M["手动选择规格/数量"]
    L --> N["加入购物车"]
    M --> N
    N --> O{"继续选购？"}
    O -->|是| Start
    O -->|否| P["结算提交订单"]
    P --> End(["结束"])
```

## 五、差异处理流程

```mermaid
flowchart TD
    Start(["发现异常"]) --> A{"差异环节"}
    A -->|拣货环节| B["创建拣货差异单<br/>短缺/残次/串货/多货"]
    A -->|配送环节| C["创建配送差异单<br/>物流破损/丢失"]
    A -->|签收环节| D["创建实收差异单<br/>少收/拒收/残次"]
    B --> E["记录差异数量/原因"]
    C --> E
    D --> E
    E --> F["责任方判定<br/>配送员/物流/仓库/供应商"]
    F --> G["金额调整<br/>更新应收账款"]
    G --> H["差异处理状态流转<br/>待处理→处理中→已处理→已关闭"]
    H --> I["审计日志记录<br/>修改前后数据快照"]
    I --> End(["归档完成"])
```

## 六、财务结算流程

```mermaid
flowchart TD
    Start(["订单完成"]) --> A["生成应收账款<br/>关联订单/商家"]
    A --> B{"存在差异调整？"}
    B -->|是| C["更新应收金额<br/>原始金额/调整后金额"]
    B -->|否| D["应收金额 = 订单金额"]
    C --> E["记录调整原因/操作人"]
    D --> F["客户结算"]
    E --> F
    F --> G{"结算方式"}
    G -->|余额抵扣| H["扣减商家余额"]
    G -->|账期结算| I["生成结算单<br/>按周期汇总"]
    G -->|现结| J["即时支付"]
    H --> K["结算状态：已结算"]
    I --> K
    J --> K
    K --> L["供应商结算"]
    L --> M["按结算周期汇总<br/>总金额-服务费=实付金额"]
    M --> N(["结算完成"])
```
