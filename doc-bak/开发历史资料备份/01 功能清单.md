# 本地速送服务平台 — 功能清单

> 基于 Laravel 技术栈，区分冷链与非冷链的本地生鲜/农产品配送平台。

---

## 一、用户与权限管理模块

| 序号 | 功能点 | 说明 |
| :--- | :--- | :--- |
| 1.1 | 用户管理 | 统一用户表，支持用户名/手机号/邮箱登录，包含头像、状态等字段 |
| 1.2 | 角色管理 | 权限角色配置（管理员/运营/财务/司机/拣货员/商家） |
| 1.3 | 权限管理 | 权限点配置，支持路由标识、菜单标识、排序 |
| 1.4 | 角色权限关联 | 为角色分配权限 |
| 1.5 | 用户角色关联 | 为用户分配角色 |
| 1.6 | 双因素认证 | 用户登录二次验证 |
| 1.7 | 密码重置 | 密码找回与重置 |
| 1.8 | 会话管理 | 用户登录会话管理 |

## 二、商家与供应商管理模块

| 序号 | 功能点 | 说明 |
| :--- | :--- | :--- |
| 2.1 | 商家档案管理 | 商家（店铺/餐厅）基本信息、配送地址、起送价、结算方式、信用额度 |
| 2.2 | 供应商档案管理 | 供应商（供货源头）基本信息、联系人、结算周期、银行收付款信息 |
| 2.3 | 配送线路管理 | 固定配送线路配置（被商家档案依赖） |
| 2.4 | 商家配送顺序 | 商家在线路中的配送顺序配置 |
| 2.5 | 数据隔离 | 基于商家的全局数据隔离（Global Scope） |

## 核心业务流程

1. **平台统采流程**：待采清单 → 生成采购单 → 供应商接单 → 备货发货 → 采购入库
2. **客户直采流程**：商家选品 → 加入购物车 → 提交订单 → 支付 → 拣货 → 配送 → 签收
3. **差异处理流程**：发现差异 → 记录差异单 → 责任认定 → 金额调整 → 审计归档
4. **财务结算流程**：订单完成 → 生成应收 → 差异调整 → 客户结算 → 供应商结算
5. **商家智能下单流程**：输入关键词 → AI 解析/联想 → 关联采购历史 + 主推商品 + 同类推荐 → 快速加购 → 提交订单
2. **客户直采流程**：商家选品 → 加入购物车 → 提交订单 → 支付 → 拣货 → 配送 → 签收
3. **差异处理流程**：发现差异 → 记录差异单 → 责任认定 → 金额调整 → 审计归档
4. **财务结算流程**：订单完成 → 生成应收 → 差异调整 → 客户结算 → 供应商结算
