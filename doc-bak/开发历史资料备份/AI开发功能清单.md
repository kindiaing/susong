# 本地速送服务平台 — AI 开发功能清单

> 本清单汇总平台中所有涉及 AI 智能体、智能推荐、数据分析、自然语言处理等未来需要 AI 能力支撑的功能模块。
> 
> **定位**：作为独立的功能蓝图，指导后续 AI 模块的接入与开发，可与主功能清单 `01 功能清单.md` 交叉对照。

---

## 一、智能商品搜索与下单模块（商家端小程序）

| 序号 | 功能点 | 场景说明 | AI 能力需求 |
| :--- | :--- | :--- | :--- |
| 1.1 | **智能语义搜索** | 商家输入"鸡"，AI 理解意图后，自动联想鸡相关所有商品（整鸡、鸡胸肉、鸡腿等），不局限于商品名精确匹配 | NLP 分词 / 语义理解 / 同义词扩展 |
| 1.2 | **采购历史关联推荐** | 搜索时优先展示该商家**近期采购过**的同类型商品，按最近购买时间排序 | 用户行为序列分析 / 历史订单召回 |
| 1.3 | **常购商品自动推荐** | 基于商家历史采购频次，自动生成"常购清单"，首页/搜索页优先展示 | 频次统计 + 协同过滤 |
| 1.4 | **相似商品推荐** | 基于商品关键词标签和品类关联，推荐商家**未买过但同类型**的商品 | 基于内容的推荐（Content-Based） |
| 1.5 | **智能排序引擎** | 搜索结果按优先级排序：**最近买过 > 常购 > 运营主推 > 同类推荐 > 其他** | 多因子排序模型 / Learning to Rank |
| 1.6 | **搜索历史记录** | 记录商家最近搜索关键词，支持快速再次搜索，AI 可基于搜索词分析采购偏好 | 搜索日志存储 + 偏好画像 |
| 1.7 | **AI 智能助手下单（未来）** | 商家自然语言输入"来两只鸡、五斤土豆"，AI 智能体解析语义、匹配商品、推荐规格、自动加购 | 自然语言理解（NLU）/ 实体识别 / 意图分类 |
| 1.8 | **语音下单（未来）** | 商家通过语音输入需求，AI 语音识别后解析为商品清单 | ASR 语音识别 + NLU |

## 二、智能补货与周期预测模块

| 序号 | 功能点 | 场景说明 | AI 能力需求 |
| :--- | :--- | :--- | :--- |
| 2.1 | **智能补货提醒** | 分析商家采购周期（如每周一固定买鸡、每3天买一次土豆），在预计采购日前主动推送补货提醒 | 时间序列分析 / 周期检测 |
| 2.2 | **采购周期分析** | 后台为每个商家生成采购周期画像，识别"习惯性采购规律" | 时序聚类 / 周期模式挖掘 |
| 2.3 | **库存预警智能升级** | 不仅基于库存阈值预警，还结合商家历史消耗速度预测补货时机 | 需求预测 / 消耗速率建模 |
| 2.4 | **快捷下单模板智能生成** | AI 基于商家历史订单自动归纳"常用组合"（如"周一进货模板"），商家一键复购 | 频繁项集挖掘（Apriori/FP-Growth） |

## 三、智能商品推荐与营销模块

| 序号 | 功能点 | 场景说明 | AI 能力需求 |
| :--- | :--- | :--- | :--- |
| 3.1 | **运营主推智能配置** | 运营端配置近期主推商品/品类，AI 自动调整搜索排序权重和首页展示策略 | 规则引擎 + 动态权重调整 |
| 3.2 | **缺货自动替换推荐** | 商家常购商品缺货时，AI 自动推荐同品类、同规格、价格接近的替代商品 | 相似度计算 / 知识图谱 |
| 3.3 | **价格变动智能提醒** | 商家常购或收藏商品发生降价/涨价时，主动推送价格变动通知 | 价格监控 + 用户订阅匹配 |
| 3.4 | **新品智能推荐** | 平台新上架商品，AI 基于商家采购偏好画像，精准推送给可能感兴趣的商家 | 冷启动推荐 / 用户画像匹配 |
| 3.5 | **商品关键词智能标签** | 为商品自动/半自动生成搜索关键词、品类标签，支撑智能联想与检索 | 关键词提取 / 文本分类 / 标签补全 |
| 3.6 | **收藏商品智能排序** | 商家收藏夹内的商品，按"最近采购过 > 常购 > 新品"智能排序 | 行为序列排序 |

## 四、智能订单复购模块

| 序号 | 功能点 | 场景说明 | AI 能力需求 |
| :--- | :--- | :--- | :--- |
| 4.1 | **订单一键复购** | 基于历史订单，商家可整单复购或勾选部分商品快速加购 | 订单结构化召回 |
| 4.2 | **周期性复购预测** | AI 预测商家"这次大概会买什么"，在下单前主动展示预测清单供一键确认 | 序列预测 / 购买概率模型 |
| 4.3 | **复购偏好分析** | 分析商家每次复购时的修改规律（如每次都多买一份葱），智能推荐增量 | 增量模式挖掘 |

## 五、AI 智能体对接架构（未来扩展）

| 序号 | 功能点 | 场景说明 | AI 能力需求 |
| :--- | :--- | :--- | :--- |
| 5.1 | **智能体商品知识库** | AI 智能体维护商品知识图谱（品类关系、同义词、规格关联、替代关系） | 知识图谱构建 / 实体关系抽取 |
| 5.2 | **智能体对话上下文** | 支持多轮对话（如"再要两只鸡"→"要土鸡还是三黄鸡"→"土鸡"） | 对话状态跟踪（DST）/ 多轮对话管理 |
| 5.3 | **智能体订单确认** | AI 推荐商品后，生成确认清单供商家核对，支持语音/文字确认下单 | 文本生成 / 结构化输出 |
| 5.4 | **智能体异常处理** | 商家说"上次那个鸡不好"，AI 理解负面反馈并推荐替代商品或记录反馈 | 情感分析 / 反馈语义理解 |
| 5.5 | **智能体个性化记忆** | AI 记住每个商家的偏好（如"李老板只要大号鸡蛋"），长期个性化服务 | 长期记忆机制 / 用户画像持续更新 |

## 六、数据基础与画像模块（AI 前置依赖）

| 序号 | 功能点 | 说明 | 优先级 |
| :--- | :--- | :--- | :--- |
| 6.1 | **商家采购行为画像** | 采集并建模商家的采购频次、偏好品类、价格敏感度、采购周期等 | 高 |
| 6.2 | **商品知识图谱** | 构建商品之间的关系网络（品类层级、同义词、替代品、搭配品） | 高 |
| 6.3 | **搜索行为日志** | 完整记录搜索词、点击、加购、下单链路，用于模型训练 | 高 |
| 6.4 | **商品向量嵌入** | 将商品信息（名称、品类、规格、价格）编码为向量，支撑语义相似度计算 | 中 |
| 6.5 | **商家向量嵌入** | 将商家采购偏好编码为向量，支撑相似商家推荐 | 中 |

## 七、AI 功能实施路线图

| 阶段 | 目标 | 涉及功能 |
| :--- | :--- | :--- |
| **第一阶段：基础数据** | 搭建数据采集与画像体系 | 6.1 商家画像、6.2 商品知识图谱、6.3 搜索日志、3.5 商品关键词标签 |
| **第二阶段：智能搜索** | 上线搜索联想与历史关联 | 1.1 语义搜索、1.2 采购历史推荐、1.4 相似商品推荐、1.6 搜索历史 |
| **第三阶段：主动推荐** | 补货提醒与个性化推荐 | 2.1 智能补货提醒、2.2 采购周期分析、3.2 缺货替换、3.3 价格提醒、3.4 新品推荐 |
| **第四阶段：智能助手** | 接入 AI 智能体 | 1.7 AI 智能助手、1.8 语音下单、5.1~5.5 智能体架构 |
| **第五阶段：深度优化** | 模型持续迭代 | 全链路 A/B 测试、排序模型优化、对话能力升级 |

## 九、关键技术选型参考

| 能力域 | 可选技术方案 |
| :--- | :--- |
| 语义搜索 / NLU | OpenAI GPT / Claude / 文心一言 / 通义千问 API |
| 向量检索 | Milvus / Pinecone / Weaviate / pgvector |
| 推荐算法 | 自研规则引擎 + 开源推荐框架（如 Merlin / Surprise） |
| 时序预测 | Prophet / ARIMA / 轻量 LSTM |
| 知识图谱 | Neo4j / Dgraph + 实体抽取模型 |
| 语音识别 | 讯飞 / 百度语音 / Whisper |
| 对话管理 | LangChain / AutoGen / 自研对话状态机 |

---

> **注意**：本清单中的功能均为未来扩展方向，第一阶段可先以"规则引擎 + 基础数据分析"实现 MVP 版本，后续逐步接入 AI 模型能力。
