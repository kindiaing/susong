### 💡 开发特别说明：

1. **数据隔离**：在 Laravel 开发中，建议为 `Merchant` 相关的 Model 使用 **Global Scope**，在查询时自动注入 `where('merchant_id', ...)`。
2. **称重逻辑**：当拣货员在 `order_items` 中填写 `actual_weight` 后，系统应自动计算 `actual_amount`。如果 `is_weighted = true` 且金额波动超过 20%，建议自动标记订单为“待运营审核”。
3. **单据锁定**：订单一旦进入“已签收”状态，对应的 `status` 应变更为不可通过 API 直接更新，必须由具有 `Finance` 角色的账号点击“授权更正”按钮，记录 `audit_logs` 后方可二次编辑。
